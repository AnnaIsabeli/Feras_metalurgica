# Fontes do PDF

DejaVu Sans (normal e negrito), incorporadas ao documento para preservar os
acentos e permitir geração sem acesso à internet. Os arquivos são distribuídos
com o aviso de licença em LICENSE-DejaVu.txt.

Projeto: https://dejavu-fonts.github.io/
Licença de referência: https://github.com/dejavu-fonts/dejavu-fonts/blob/master/LICENSE

Não substituir por fontes que exijam download durante a geração do orçamento.
